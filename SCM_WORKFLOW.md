# SUAMS Configuration Management Workflow

This file documents the Git/GitHub workflow used for the Smart University Academic Management System proposal.

1. Protect `main` as the production branch.
2. Create a focused feature branch, for example `feature/exam-result-validation`.
3. Commit small, reviewed changes with descriptive messages.
4. Push the feature branch and open a pull request into `main`.
5. Require peer review and passing automated tests before merging.
6. Merge the pull request, delete the feature branch, and create a version tag for a release.
